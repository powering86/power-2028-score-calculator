# POWER 2028 학생부 환산기

2028학년도 대학입학전형 시행계획 원문을 근거로 한 브라우저 내 학생부 환산 정적 웹 프로그램입니다. 기존 `admission-atlas-2028`은 수정하지 않았습니다.

- 실행: OCR 워커 로드를 위해 `./start-preview.ps1`로 정적 서버를 실행한 뒤 `http://127.0.0.1:8768/` 접속. `file://` 직접 열기는 브라우저 보안 제한으로 OCR이 동작하지 않을 수 있음.
- 테스트: `npm test`
- Cloudflare Pages: 빌드 명령 없음, 출력 디렉터리 `dist`
- 규칙 데이터: `dist/data/score-rules.js`
- 계산 엔진: `dist/calculator.js`
- 성적표 사진 OCR: 한국어·영어 모델을 `dist/vendor` 안에 포함하며, 이미지를 외부 API로 전송하지 않음
- OCR 결과는 검토 테이블에서 사용자가 확인한 행만 상세 성적에 추가

현재 실재하는 220개 대학·캠퍼스 전체에 계산 가능 상태와 원문 근거 상태를 등록하고 시행계획 원문을 연결·추출했습니다. 원본 목록에 섞여 있던 `KCUE대학교`는 내용이 전혀 없는 1쪽짜리 시험용 PDF를 가진 가상 항목임을 확인하여 공개 목록과 통계에서 제외했습니다. 정확 계산 범위는 94개 대학·110개 캠퍼스이고, 계산 차단 또는 일부 계산은 110개 캠퍼스입니다. 시행계획에 핵심 환산식이나 표가 없거나 HWP/PDF 내장 표의 숫자 복원 검수가 끝나지 않은 전형은 공개된 반영 범위와 근거만 기록하고 총점 계산을 차단합니다. 계산 가능 규칙에도 모집단위·교육과정·학교폭력 등 미공개 분기가 있으면 해당 조건에서만 안전하게 중단합니다. `npm run coverage`로 전체 상태표와 `docs/review-queue.csv`를 갱신할 수 있습니다.

- 대학·전형 규칙 273개: 계산 가능 146, 일부 계산 가능 54, 상세 기준 미공개 6, 모집요강 확인 필요 57, 해당 전형 미반영 9, 원문 확인 불가 1
- 간편 입력: 공개된 평균등급 구간표 또는 독립된 출결 감점만 계산하며 나머지는 상세 입력·미공개 상태로 안내
- 상세 입력: 대학 규칙에 필요한 열과 출결 항목만 노란색으로 표시
- 사진 입력: 로컬 OCR 후 사용자가 확인한 행만 상세 입력에 추가
- 나이스 개인성적 엑셀: `.xlsx`를 브라우저에서만 해석하고, 검토 화면에서 선택한 과목만 상세 입력에 추가 (`.xls`는 `.xlsx`로 저장 후 사용)
- 개인정보: 로그인·분석 스크립트·성적 서버 전송 없이 브라우저에서만 계산
- 완성도 감사: `docs/completion-audit.md`
