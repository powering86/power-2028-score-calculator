# POWER 2028 요구사항 완성도 감사

기준일: 2026-10-25

## 전체 원문과 대학 범위

- 실재 대학·캠퍼스 220곳을 `dist/data/universities.js`에 등록했다.
- 220곳 모두 `dist/data/coverage.js`에서 공식 시행계획 원문 URL 또는 배포된 로컬 원문에 연결된다.
- 원문 텍스트 추출과 캠퍼스 상태 검수는 220곳 모두 완료했다.
- 가상 시험 항목인 KCUE대학교는 빈 1쪽 PDF임을 확인한 뒤 공개 목록과 통계에서 제외했다.
- 규칙 273개 모두 원문 ID, 근거 쪽수, 표 제목, 검수 상태를 갖는다.

## 계산 가능 범위

- 계산 가능 규칙 146개는 공개된 식과 표만 사용한다.
- 일부 계산 가능 54개는 공개된 교과·출결 구성점수만 계산하고 최종 총점과 구분한다.
- 상세 기준 미공개 6개, 모집요강 확인 필요 57개, 원문 확인 불가 1개는 누락된 식을 추정하지 않는다.
- 학생부 정량 환산을 하지 않는 9개 규칙은 `해당 전형 미반영`으로 표시한다.
- 캠퍼스 기준으로 정확 계산 전형이 있는 곳은 110곳, 계산 차단 또는 일부 계산 상태는 110곳이다.

## 입력과 개인정보

- 간편 입력은 평균등급만으로 공개 구간표가 완성되는 경우와 독립 출결 감점만 계산한다.
- 상세 입력은 학년·학기·교과·과목·유형·학점·등급·성취도·P/F·수강자 수·석차·공동석차·원점수·평균·표준편차·성취도별 분포·현재 성취비율을 구분한다.
- 대학 규칙에 필요한 성적 열과 출결 항목만 동적으로 필수 표시한다.
- CSV·JSON 가져오기/내보내기, 행 추가·복사·삭제·학기 일괄 추가를 제공한다.
- 사진 OCR은 배포물 안의 Tesseract 워커와 한국어·영어 모델만 사용하며, 확인된 행만 입력에 반영한다.
- 성적은 서버로 전송하지 않는다. 저장은 사용자가 선택한 경우에만 localStorage를 사용하고 전체 삭제로 저장본·입력·사진·비교 결과를 함께 제거한다.

## 결과와 근거

- 대학·캠퍼스·전형·모집단위, 반영 학기와 선택 방식, 학생부 배점·점수 범위·출결 상태를 표시한다.
- 계산 결과는 교과·출결·봉사·학교폭력, 만점 대비 비율, 과목별 과정, 학년·학기별 요약, 제외 과목과 사유로 나눠 표시한다.
- 모든 규칙에서 공식, 원문 쪽수·표 제목·검수 상태와 원문 확인 링크를 제공한다.
- 비교표는 원점수 또는 공개 구성점수, 만점 대비 비율, 계산 상태를 함께 보여주며 합격 가능성을 예측하지 않는다.

## 검증 게이트

- `npm test`: 데이터 연결, 대표·확대 대학 계산식, 입력 부족, 미공개 기준 차단, 출결, 개인정보, CSV/JSON, OCR, 모바일 UI 회귀 테스트.
- `node --check`: 앱·계산기·검증기·규칙 데이터의 문법 검사.
- 브라우저 실동작: 상세 입력 계산, 비교표, P/F 분리 입력, 규칙별 출결 필수 안내, 간편 평균등급 계산을 로컬 정적 서버에서 확인했다.
- Cloudflare Pages는 빌드 명령 없이 `dist`를 출력 디렉터리로 배포한다.

## 운영 시 주의

- 시행계획은 최종 모집요강이 아니다. 화면 상단과 결과에서 최종 모집요강 및 대학 공식 계산기 확인을 경고한다.
- 새로운 모집요강이 공개되면 현재 `모집요강 확인 필요` 또는 `상세 기준 미공개` 규칙을 원문 대조 후 갱신해야 한다.
