# 2028 학생부 환산기 초기 분석

## 1. 원문 구조와 연결 현황

- 현재 공개 카탈로그: 실재하는 220개 대학·캠퍼스. 모두 시행계획 원문 또는 통합·공통 시행계획 원문에 연결되어 있다.
- 원본 수집 목록의 `KCUE대학교`는 완전히 빈 1쪽짜리 시험용 PDF를 가진 가상 항목으로 확인되어 공개 목록과 통계에서 제외했다.
- `work/all-plans/manifest.json`과 `extraction-manifest.json`은 최초 수집 상태를 보존하며, 현재 사용자용 연결 상태는 `docs/coverage-summary.json`을 기준으로 한다.
- 중복 캠퍼스를 합친 대학명은 193개이며, 계산 규칙은 반드시 캠퍼스·전형·모집단위 단위로 나누어야 한다.

## 2. 추출 난이도

- 자동 구조화 용이: PDF 텍스트에 반영 교과, 등급별 점수, 산출식, 출결표가 문자로 남은 경우.
- 반자동+수동 검수 필요: 표의 행·열 순서가 풀린 PDF, 전형·계열별 예외가 많은 경우.
- 추가 변환 필요: HWP·압축 내 복수 문서, 표가 이미지로만 존재하는 경우.
- 계산 불가: “모집요강 참조”, 환산표 미공개, 정성평가만 있는 경우.

## 3. 공통 데이터 필드

`university`, `campus`, `admissionType`, `admissionName`, `applicableUnits`, `graduationCohort`, `semesters`, `includedSubjects`, `excludedSubjects`, `selectionRule`, `gradeConversionTable`, `achievementConversion`, `achievementRatioRule`, `creditWeighting`, `attendanceRule`, `maximumScore`, `minimumScore`, `roundingRule`, `exceptions`, `calculationStatus`, `evidence(planId,file,pages,table)`, `verificationStatus`, `reviewer`, `reviewedAt`.

## 4. 간편/상세 계산 구분

- 간편 계산 가능: 평균등급 자체를 별도 가중 없이 선형 환산하는 경우에만 한정.
- 제한적 추정: 전 교과 평균을 쓰지만 이수학점·성취도가 결과를 바꾸는 경우.
- 상세 입력 필요: 반영 교과, 상위 N과목, 이수학점, 원점수·평균·표준편차, 성취비율을 쓰는 경우.
- 시행계획상 계산 불가: 세부 환산표/산출식이 없거나 정성평가인 경우.

## 5. 대표 후보 5개교

1. 경기대: 이수학점 가중 등급/성취도 환산과 출결 구간이 모두 명시됨.
2. 서원대: 교과군별 상위 과목 선택과 5등급/성취도 점수 환산.
3. 경운대: 상위 11과목, 국·수·영 최소 3과목, 9등급→5등급 변환.
4. 한동대: 원점수·석차등급·성취도 중 최고점을 쓰는 특수형이지만 환산표 미공개로 계산 차단 사례.
5. 국립부경대: 성취도별 분포비율·원점수·이수학점·출결을 함께 쓰지만 2028 세부식 일부 미공개 사례.

## 6. 계산 엔진

규칙 데이터 → 입력 검증 → 학기/교과 필터 → 과목 선택 → 지표 환산 → 가중평균 → 출결·가감점 → 소수점 처리 → 근거와 계산 과정 출력으로 분리한다. 환산표가 없으면 엔진은 반드시 `blocked`를 반환한다.

## 7. 개인정보 보호

정적 파일만 사용하고 성적 전송 API·로그인·분석 코드를 두지 않는다. 로컬 저장은 사용자 체크 후에만 실행하고, 전체 삭제·JSON/CSV 내보내기를 제공한다.

## 8. 구현·검수 계획

1. 원문 파일 대응표를 고정하고 원문 미공개 4건을 분리한다.
2. 후보 5개교의 표를 페이지 단위로 2인 대조한다.
3. 수작업 산출 예제를 테스트 코드로 고정한다.
4. 반올림/버림, 졸업연도, 모집단위 예외를 경계값 테스트한다.
5. 검수 완료된 규칙만 “계산 가능”으로 승격하고, 나머지는 “검수 중”이나 “모집요강 확인 필요”로 유지한다.
